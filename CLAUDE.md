# Project instructions

## Skills

- Remotion skills are installed in `.claude/skills/` (managed with `npx skills`, pinned in `skills-lock.json`).
- Always use the `remotion-best-practices` skill for any video, motion-design, or animation work: creating or editing Remotion compositions, animating with `interpolate`/`spring`, sequencing scenes and transitions, captions/subtitles, audio, GIFs/Lottie/3D, charts, or rendering to MP4. Consult it before reaching for a Remotion API.
- To install the same skills in another project, run: `npx skills add remotion-dev/skills` (add `-g` to install user-wide for all projects on a machine).
